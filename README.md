# 河北高考录取查询站

985 / 211 / 双一流高校在河北省的本科批分专业投档最低分、全省位次、招生人数，附 26 / 25 届保研率。

纯静态站点，只有两个文件，无构建步骤、无外部依赖：

- `index.html` — 页面与全部前端逻辑
- `data.json` — 院校、专业、投档分、位次、保研率数据

## 本地查看

直接双击 `index.html`，或在本目录起一个静态服务：

```bash
python -m http.server 8000
```

## 部署

任意静态托管都能用：GitHub Pages、对象存储、Nginx 直接放目录均可。

## 数据来源

- 投档分与位次：河北省教育考试院本科批平行志愿投档情况统计（2024 / 2026）、GaokaoCompass 公开数据集（2025）
- 保研率：公开推免统计（26 / 25 届），院校级指标，非分专业

## 说明

保研率为院校级数据，官方不公布分专业推免名额，因此同一学校所有专业共用一个数值。部分校区/分校无独立数据，采用校本部数据并标注。
